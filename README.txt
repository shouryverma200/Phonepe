UPI Balance Simulator - Educational Demo

How to run:
1. Extract this ZIP file.
2. Open upi_demo_simulator.html in Chrome, Edge, or another modern browser.
3. Use the simulator's on-screen controls to manage fictional demo data.

Important: This is an educational simulation only. It does not connect to a bank,
does not perform real UPI payments, and does not verify a real account balance.
Never enter a real UPI PIN, OTP, or banking credentials.
